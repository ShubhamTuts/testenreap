# Dhan Mudra WebView App

Minimal Android WebView app for https://dhanmudracapitaladvisor.com/login

- Animated branded splash.
- Web page loads immediately behind the splash.
- HTTP/HTTPS navigation stays inside WebView.
- JavaScript, DOM storage, cookies and HTML file upload enabled.
- Android back button navigates WebView history.
- No toolbar, ads, analytics SDK, tabs or unnecessary native UI.

Package: com.dhanmudra.capitaladvisor
Version: 1.0.0 (1)
minSdk 24 / targetSdk 36
